A reusable starting point

Warming up a ViT on non-visual procedurally generated data can improve subsequent learning, but a separate warm-up is needed for each target model (Shinnick et al., CVPR 2026). Procedural Core captures this learned structure in a compact set of recurrent weights. In our main setting, a 1-million-parameter core initializes an 85-million-parameter ViT-Base and improves final ImageNet-1K top-1 accuracy from 77.6% to 79.8%. The same set of weights initializes ViTs of different widths and depths, transferring the benefits of procedural warm-up without warming up each target model separately.

01 / THE IDEA

Recurrence learns compact weights that can be expanded

A small recurrent model first learns on non-visual procedural data. We then expand its learned weights in width and depth to initialize a larger ViT, whose layers train independently on images.

01

Learning Procedural Core

Our recurrent model has three unique layers and predicts masked closing tokens in bracket sequences, with a looped middle layer.

02

Expand the weights.

Tile and rescale matrices to match the target width. Copy the recurrent middle block across the target’s middle layers, keeping distinct first and last blocks.

03

Image training

The target layers are untied and train independently during standard image training. The core provides the initialisation.

02 / THE EVIDENCE

Performance of Procedural Core

We compare ImageNet classification accuracy across initializations, then evaluate spatial tasks with the trained backbones frozen. DINO uses the same initialisation as the supervised vision experiments. Language and code experiments use a separately trained GPT-style recurrent model matched to the target architecture.

03 / INSIDE THE MODEL

Reducing attention sinks

Attention sinks are tokens that attract a disproportionate share of attention. In the trained ViTs, high-norm patch tokens show this behavior. Procedural Core reduces both these outliers and the attention they receive.

The value/output pathway matters

Shuffling value/output weights before image training restores default-like attention to high-norm tokens and removes much of the transfer benefit. Shuffling query/key weights largely preserves the reduced attention to outliers and the transfer gains (Figure 10).
