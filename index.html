01 / THE IDEA

Learn once.
Initialize many.

Procedural warm-up learns useful structure, but has to be repeated for each model. Procedural Core compresses that structure into a small set of weights you can reuse.

01

Learn abstract structure.

A small transformer learns from nested procedural tokens. It has just three unique blocks: a first block, a shared recurrent middle block, and a last block.

02

Expand the weights.

Unroll the middle block to increase depth. Tile and rescale weight matrices to increase width. The compact core becomes the target model’s initialization.

03

Train as usual.

The target layers are untied and free to diverge during standard training on real data. The core supplies a starting point; the target still learns the task.

~1M → 85M describes the initialization’s parameter expansion. The resulting ViT-Base still has ~85M parameters.

02 / THE EVIDENCE

A better start.
A measurable difference.

The benefits carry through standard training, from image classification to spatial understanding. Architecture-compatible cores also improve language and code modeling.
